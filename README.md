## 🛠️ How to Run

Make sure you have a C compiler installed, such as **GCC**.

### Compile

```bash
gcc program.c -o program
```

### Run

On Linux/macOS:

```bash
./program
```

On Windows:

```bash
program.exe
```

## 🧪 Example

```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

Compile and run it with:

```bash
gcc hello.c -o hello
./hello
```
